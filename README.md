# StoreStar

Desenvolvemos o StoreStar para ajudar pequenos empreendedores e grandes empresas a gerenciar seus negócios de forma segura e responsável, dando acesso a tecnologias de ponta que antes pareciam distantes.
Acreditamos que organização e boas ferramentas não devem ser privilégio de poucos. Cada recurso é pensado para ser simples de usar e poderoso nos resultados.
